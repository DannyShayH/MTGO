MTOGO is the team's food-ordering platform, built on Medusa. This site is the one place for the product owner, the teacher and the team to follow the project: what we are building, how it is built, how we work, and how the work flows.

## Start here

- **Board:** [GitHub Project #2](https://github.com/users/DannyShayH/projects/2), the Kanban board with the prioritised backlog and WIP limits.
- **Code:** [DannyShayH/MTGO](https://github.com/DannyShayH/MTGO) on GitHub.
- **Running application:** not deployed yet. Stage and production links will appear here when the Medusa app has its own environments.
- **Current version:** no release yet. See [Releases](/MTGO/releases/).
- **Team and roles:** see [How we work](/MTGO/way-of-working/how-we-work/).
