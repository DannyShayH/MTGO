Published 2026-11-17. [GitHub release](https://github.com/DannyShayH/MTGO/releases/tag/0.3.0).

Customers can review a one-Restaurant basket, pay and receive an Order
reference, and operators can recognise dishes in Medusa Admin. This completes
Feature #46.

## What Customers can do

- Build and review a basket from exactly one Restaurant, with the final price.
- Pay and place an Order. The Order is placed awaiting Restaurant acceptance
  and gets a durable reference, so refreshing or retrying does not buy the same
  food twice.
- Recover from an immediate payment failure and retry.
- See an uncertain payment as pending, and get the delayed result when it
  arrives.

## What operators can do

- Medusa Admin Products reflect Restaurant dishes.
- Registered dish photos show as thumbnails in the Admin Products list and on
  Order items. Order items show the current dish photo, not a historical
  snapshot.

## Delivery and quality

- Release pages are on the docs site, and the flow metrics page has a Ready
  limit of 10, grouped Related Features and a retry for temporary GitHub
  errors.

## Current scope

Payment is a mocked external supplier. Restaurant acceptance, delivery and
refunds follow in later releases. MTOGO remains under development.
